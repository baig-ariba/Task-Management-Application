# Task Management Application

#### Visit the webpage at : https://baig-ariba.github.io/Task-Management-Application/

The application takes the input for the tasks from the user. The default values for the status is in progress in case the user does not want to type it in and it checks against todays date and updates the status itself. The user can update the status of the tasks themselves once the tasks have been inserted into the task table.

The user can filter their tasks by category or status whichever one they want to.

The category and status have been hard-corded though .
